# Project Final Review and Reflection

## Addressing Relevant Implications

### Usability

For my project, because RAD handles so many devices I decided to add a method of searching and filtering devices so that a user would not have to spend large amounts of time scrolling through the dashboard to find a relevant device.  
I also used colors in the system status so that users would be able to quickly comprehend the status of a device without having to actually read it


### Accessibility

My website largely uses flexboxes to ensure that the website will function on a variety of displays so that users arent forced to use any one device


### End-User

I had consistent communication with my stakeholder mr taylor during key moments of the project and he inspired many features such as the condition pills, timestamps and filter + search options.  
I belive that my final result has met most specifications and that anything not finished is mostly cosmetic.


### Fuctionality

Functionality was the first aspect of the site I finished as this is one of the most important aspects for this site concidering the end-users wouldnt be too upset by lacking cosmetics.
