# Project Requirements

## Identified Problem or Need

In RAD is has been tedious to keep track of all the devices, who last worked on what, and what has been acomplished per device


## End-User Requirements

My typical end users will be RAD techs who are overwhelmed with a large amount of unfinished computers and are unsure the progress
made on any given computer.

## Proposed Solution

I indend to create a website which, when viewed on mobile, allows the user easily and immediately view the status of all devices regestered
or filter them based on specific cases (such as; "Currently being worked on", "Not started", "Finished", "Unfinished" or "Bricked")
This website should also be able to provide information on who last worked on a specific device and notes left by past techs.

# Relevant Implications

## User system

The website will need the ability to manage multiple users and information including login pages and passwords.

### Relevance to the System

A user system is needed due to the nessesity of tracking who last worked on a specific device.

### Impact / Considerations

This will require systems to manage and authenticate users as well as capability to efficiently add or remove users.



## Computer database

The computer database is a database containing information on the various computers handled by RAD
including Serial no., last tech, status and relevant notes.

### Relevance to the System

This is relevant to the system due to the nessesity of handling the status and information about the various computers that RAD processes.

### Impact / Considerations

I will need to implement the ability to modify computer information or add computers via requests to the database.
It may also require the ability to scan barcodes, to more easily add computers via their serial numbers.
